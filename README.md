Every skill I use on a daily basis to optimize my workflow.

- **direct-readable-code** — write, edit, refactor, test, and review code in a direct, human-readable style optimized for first-pass understanding.
- **plain-technical-explainer** — explain technical and specialized concepts in simple, jargon-free language for non-experts.
- **project-init** — set up and maintain a project's CLAUDE.md and docs (Architecture, Prod-Spec, Milestones) so coding sessions stay grounded in a real spec.
